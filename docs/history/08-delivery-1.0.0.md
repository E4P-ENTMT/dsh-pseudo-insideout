## 使用时需要知道的行为

- 封存浏览、单回合临时调阅、恢复活跃是三个不同操作。DSH 已经保存的聊天历史不由本插件撤回；停止重新注入不能保证旧文本从宿主历史消失。
- 核心记忆和人格岛需要批准；人格岛是有证据、可修正的主题倾向。整理只生成建议，跟进只形成控制台待办，不自动向外发消息。
- 当前检索采用词法和结构匹配，不是 embedding 语义检索。没有模型时仍可手动管理记忆、召回、封存和整理。
- 自动捕获针对正常完成的根会话真人输入；失败、中止回合与子 agent 不进入捕获，超大输入及超配额等核心捕获跳过会记录原因。已经保存的记忆不受这些限制影响。
- 宿主情绪分析默认可使用现有模型增加一次辅助调用，可通过 `analyzeTurns:false` 关闭；本次真实宿主验收关闭了该调用。
- 删除仅响应完整 ID 确认，不清理外部备份、导出或 DSH 聊天历史。卸载保留数据。备份恢复到新目录，并清空旧的临时调阅授权。

本次交付未发布到 npm，未安装进用户原有 profile。安装包可按安装维护文档用于受支持的本机 Web profile；在线模型相关的未测边界应在实际使用环境中按 HOST-03/04 清单核对。
