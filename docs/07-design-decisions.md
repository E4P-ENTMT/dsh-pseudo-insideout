# 设计变更与瀑布回溯记录

2026-10-29，1.0.0。

| 决策 | 理由 | 实现/验收影响 |
|---|---|---|
| 产品名固定 dsh-pseudo-insideout | 用户明确指定 | 包、插件行、控制台和文档一致 |
| 忘记改为独立封存 | 用户不希望真正丢失记忆 | 双数据库，普通召回不连接封存，删除独立确认 |
| 真实DSH插件而非仅原型 | 用户再次明确平台与瀑布模式 | 官方Cordis、client工厂、manifest与bundle patch、真实CLI安装验收 |
| 锁定0.2.2-alpha.2 Web | 官方预览接口快速变化 | 不宣称全部DSH版本/Desktop兼容 |
| 成功终态捕获 | turn-stopping仍可能被steering续跑 | 使用session/event turn/end completed |
| 临时调阅只承诺单次新注入 | DSH真实SystemPrompt会形成历史snapshot | UI/说明明确宿主历史不可撤回 |
| JSON + SQLite分库、零运行依赖 | 可安装、可诊断、跨平台路径和事务要求 | Node>=24.9，DELETE journal跨库原子移动 |
| FTS独立secure-delete | 独立测试发现普通PRAGMA不足清FTS词项 | 主/冷库同时开启FTS选项，字节残留回归 |
| data_version缓存与原子grant认领 | 独立审查发现跨进程失效及竞争 | 两实例封存/并发认领回归通过 |
| 源修改传递封存派生 | 修订原文后旧摘要仍可能错误召回 | 引用闭包封存、来源hash恢复检查 |
| 损坏记录逻辑隔离 | 单坏记录不应阻断健康记忆 | 不抹除原字节，持续告警，坏证据返回无效 |
| 词法+结构检索明确标注 | 当前无需外部embedding服务 | 不冒称向量语义检索；保留可替换排序模块 |
| 主动关怀只生成待办 | 不在未明确配置时向外自动发话 | 无定时外发、无离线惩罚、无好感绑架 |
| UI分页和scope选择 | 真实多工作区与大量记忆可管理 | offset、core筛选，旧scope响应丢弃 |
| 内嵌面板跟随宿主高度 | 真实DSH设置容器低于固定760px时，模态底部按钮被裁住 | iframe使用容器100%高度，浏览器复测创建按钮 |

需求阶段明确用户硬要求；设计阶段固定存储、接口与宿主契约后再实现。测试发现的偏差回溯设计并更新文档与回归，并非把未完成模块递延成下一阶段。1.0交付后如要扩展云同步、外部embedding、Desktop原生集成或自动外发，应建立新变更范围和验收，不默默改动本版行为。

## 1.0.1 外观变更（2026-10-30）

用户要求寻找 Inside Out 图片并将控制台配色靠齐。参考 Pixar 官方总部和记忆库图片，改为蓝紫表面、暖金主操作及鲜明情绪色；同步记忆球高光、全六色图例、表单与移动端。数据与宿主行为不变。图片出处、可读性与浏览器验证见 [配色记录](09-insideout-palette.md)。

## 1.1 成长能力补齐（2026-10-30）

本轮回到最初目标补齐普通对话到成长的闭环，不能以手工标签或静态页面代替自动能力。先补充 [需求与接口基线](10-growth-completion.md)，再实现并逐项验证。

| 变更 | 设计理由与验收影响 |
|---|---|
| 结构化提炼与保守离线规则 | 原话单独保留；偏好/关系/习惯/价值/兴趣只作有来源候选，条件句/虚构/助手内容不能直接变成用户事实 |
| 模型语义选择与原生只读工具 | 只发送有限活跃可见候选，回传再校验版本、日期与范围；无模型时有限双语概念回退 |
| 来源闭包覆盖全部分析输入 | 模型可能引用未显式标注的背景；封存/修订背景后撤销受影响元数据和历史，保留后续原话 |
| 人格版本与恢复指纹 | 增长记录可回退；档案恢复须来源未变，保持停用；无指纹旧记录拒绝盲目恢复 |
| 会话工作台与逐轮观测 | 用户目标、注意与固定工作记忆受范围和预算约束；只记录实际注入状态与真实辅助调用回执 |
| 回收箱和批量事务 | 可恢复移除使用独立档案，不生成隐藏撤销副本；批量错误整体回滚 |
| 时区与后台维护 | 自然日期按配置时区；到期/安静时段/频率真实执行，卸载取消定时器；仍只生成控制台待办 |
| 完整真实宿主配合合成SSE供应商 | 验证真实agent生命周期、下一轮注入、跨会话排除、官方工具执行和用量；不据此宣称真实模型质量已验证 |


## ADR-1.2：默认继承、会话覆盖与显式导入

用户追加全局默认、session开关及选择性导入，随后确认同时支持JSON/TXT/Markdown。实现采用profile单独默认库与scope本地三态覆盖，避免将一个空间配置误称为全局。已有记录采用保留来源的引用授权，不复制为共享正文；整会话导入固定为所选快照。DSH仅调用官方公共只读历史API；文件只处理明确选定内容，保存为未经核验的外部参考。所有来源先预览、选择、提交，最多200条/批，变更竞争整批拒绝；关闭期间仍允许手动导入但不自动开启。

仍使用schema1可加表扩展，保留旧数据兼容；额外默认库不含正文，单空间双库备份不包含profile默认库，此边界在安装手册说明。组件、浏览器与官方完整宿主分别验证；完整宿主使用本机合成模型，真实商业供应商质量不计入已验证范围。
