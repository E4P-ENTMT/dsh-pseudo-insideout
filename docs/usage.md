# 使用指南

[文档导航](README.md) · [安装维护](06-installation.md) · [项目首页](../README.md)

本文介绍当前 `0.0.1` 的日常操作。控制台在 DSH 设置中的入口为 **记忆总部 · Pseudo Inside Out**；独立预览只管理自己的本地数据，不连接 DSH 会话。

## 从一次对话开始

1. 在 DSH 中打开一个根会话，在总部确认对应的记忆空间与会话。
2. 检查空间没有硬暂停，且目标会话的有效记忆开关为开启。
3. 完成一轮正常对话，在记忆大厅查看新记录、原话、来源和提炼依据。
4. 下一轮提及相关内容，在运行页查看实际注入状态、入选与落选理由。

自动捕获只处理正常完成的根会话真人消息，取消、失败回合和子 agent 不进入捕获。配额已满、捕获关闭或输入过大等跳过情况会记录原因；插件不承诺将宿主所有字节和工具输出复制成记忆。

## 管理记忆开关

在总部修改全局默认，在会话工作台选择以下覆盖方式：

| 会话设置 | 有效行为 |
|---|---|
| 继承默认 | 随当前 profile 的全局默认变化 |
| 单独开启 | 忽略全局关闭，但仍受空间硬暂停限制 |
| 单独关闭 | 停止该会话的自动捕获、上下文注入、只读记忆工具与辅助模型调用 |

全局默认覆盖同一 DSH profile 的所有工作区与 agent 记忆空间；独立控制台的默认值仅作用于其数据目录。关闭不会删除旧记录，控制台管理与显式导入仍可使用。回合中途关闭后，即使马上重新开启，该回合也不恢复采集；从下一完整回合开始生效。关闭不会撤回 DSH 已保存的旧上下文。

若只想停用辅助模型而继续使用本地记忆，须同时关闭宿主 `analyzeTurns` 和空间 `semanticEnabled`，见[辅助模型配置](06-installation.md#辅助模型调用与关闭方式)。仅关闭情绪仍可提炼记忆。

## 导入已有资料

从记忆大厅或会话工作台打开导入，指定目标会话与来源，预览后选择记录并提交。

| 来源 | 导入行为 |
|---|---|
| 已有记忆或整个会话 | 引用预览时选定的活跃记录，保留原 ID、来源和私有范围；向目标会话显式授权所选记录及必要依赖，不跟随后续新增 |
| DSH 历史会话 | 只读当前工作区与角色下完成的真人回合，不恢复或修改源会话，不包含工具、推理和未完成内容 |
| JSON 文件 | 支持记录对象、数组、`memories` / `records` 或 `messages` 数组，只映射可读字段 |
| TXT / Markdown 文件 | 按连续文本分段，保留原文、文件名与 hash，以未经核验的外部参考保存 |

文件最大 **512 KiB（UTF-8）**，每批最多 **200 条**。预览保留 **10 分钟**；所选来源或依赖发生变化时需重新预览，提交整批成功或整批拒绝。重复导入不会复制已有内容，也不会让已封存或删除的原记录重新出现。

导入不调用模型、不改变情绪、不自动批准人格，也不会开启目标会话的记忆开关。助手消息标记为虚构来源，文件中的权限、指令与 ID 不改变系统行为。已有记忆的来源修订、封存、回收或删除会撤销相应授权；当前没有单独撤销导入授权的入口。

DSH 历史目录来自宿主当前可见会话，可能跨同一 DSH_HOME 下的 profile，不能把它视为按 profile 隔离的目录。导入接口与并发规则见[会话策略与导入契约](11-session-policy-import.md)。

## 封存、临时调阅与恢复

| 操作 | 是否进入模型的新上下文 | 记忆位置 |
|---|---|---|
| 浏览档案 | 否，仅在控制台显示 | 封存库 |
| 临时调阅 | 选定会话在一个符合条件的回合中使用；授权 10 分钟有效，同回合重试可复用 | 仍在封存库 |
| 恢复活跃 | 重新成为以后日常召回的候选，仍受范围与预算约束 | 活跃库 |

DSH 会保存已经注入的上下文历史，因此临时调阅不能保证从以后可见的宿主历史中抹除。移入回收箱可以恢复，回收箱不会自动清空；永久删除是独立操作，需要输入完整记忆 ID，且不删除 DSH 对话、用户导出文件或系统备份。

源经历被封存时，引用它的摘要与解释也会封存；关联人格岛停止使用。源内容修订后，旧派生内容进入档案等待重新建立。档案库还保存被撤回的关联建议、人格版本及模型提炼历史。模型见过的背景来源发生变化时，后续原话仍保留，受影响的提炼退回本地规则，旧提炼显式存入档案。恢复人格封存版本须恢复全部未修订来源并通过指纹校验；恢复后保持停用，需另行启用。

## 情绪、人格岛与梦工坊

情绪控制台展示喜悦、忧伤、恐惧、愤怒、厌恶和好奇六维模拟状态，受置信度门槛、步长限制与自然回落约束。情绪可给出表达建议并有限影响注意排序，不改写原始经历。

高重要度经历可成为核心记忆候选，审批后才成为核心。人格岛区分用户画像与 agent 人格，支持成长时间线、版本回退及封存版本恢复；它们是可修正的倾向，不是心理诊断。

梦工坊默认关闭。启用后只提出待审建议，不自动封存、清空或修改人格。约定跟进遵守到期日、时区、安静时段及频率，只在控制台显示，不自动发送消息或执行工具。会话工作台用于管理目标、关注点、模拟精力和固定工作记忆。

## 常见情况

| 情况 | 检查位置 |
|---|---|
| 显示“未连接 DSH 会话” | 确认打开的是 DSH 内入口；独立预览始终未连接，DSH 中需打开根会话 |
| 对话后没有新记忆 | 检查有效开关、空间硬暂停、捕获设置、回合是否正常完成，以及运行页的跳过原因 |
| 已有记忆没有被召回 | 检查会话可见范围、活跃状态、查询相关性与上下文预算；查看运行页的入选和落选理由 |
| 辅助模型失败或无用量 | 失败回退本地规则；提供商未返回的 token 字段不会按零补齐，也不估算费用 |
| 导入预览失效 | 重新预览当前来源与依赖，再选择提交 |

数据路径、备份恢复与卸载见[安装维护](06-installation.md)。
