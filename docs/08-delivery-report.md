## 审查修复与检索优化（2026-11-05）

本轮完成以下修复：普通条件句或代码中的 `if` 不再使独立真实陈述整条失去召回资格，混合条件内容保守保留为经历；虚构标记可通过有修订记录的编辑纠正；语义候选按问题排序并实际采用改写词；首次连接可通过刷新自动切换至有效空间；新建记忆默认尊重当前选定会话；结构不完整的记录被隔离且原始字节保留。

控制台新增空间级「允许辅助模型调用」总开关，无需改宿主配置即可停用并取消两类辅助请求，同时保留本地捕获与检索。表单显示目标会话，已知会话优先展示名称。

活跃搜索启用 FTS5 词语/概念候选索引、持久派生特征及有界内存缓存。旧库首次检索补建派生索引，其他连接的修改由脏项队列重建；编辑、封存、删除、会话和证据隔离继续校验。上下文仍需扫描活跃记录以保留长期事实、固定记忆和关联候选。

## 跨会话记忆修复（2026-11-06）

自动捕获从固定 session 改为默认 workspace，在同一 profile、工作区与 Agent 内跨会话召回。控制台可将之后的自动记录改为仅来源会话，范围改变会使进行中的旧策略任务失效。使用私有分析背景的捕获保持私有；手动记录和显式导入不自动共享。旧版未修订、未添加解释且无私有依赖的活跃自动记录一次性迁移，原文与来源保留，迁移失败整批回滚；不打开封存库。

源码自动测试 **129/129** 通过，新增 7 项核心回归和 1 项官方 Cordis 宿主跨会话/重启回归。浏览器核对默认共享、切为私有并保存刷新、恢复共享。候选包在 DSH `0.2.1-rc.1` 与 `0.2.2-rc.1` 各通过 **16/16** 完整合成宿主检查，包括第二会话的真实模型请求中出现第一会话记忆，以及私有范围配置；测试使用本机合成提供商。最终包与完整宿主报告保存在 `output/cross-session-2026-11-06/`，按报告中的 SHA-256 核对工件。其他六个宿主版本本轮未重跑。
