## 应用色板

以下是为屏幕阅读调整的项目色板，不是电影官方色值规范。

| 用途 | 色值 |
|---|---|
| 主背景 / 侧栏 | `#17132f` / `#15112d` |
| 卡片 / 次级表面 | `#292344` / `#352c55` |
| 正文 / 次要文字 | `#fff7e9` / `#afa2c8` |
| 主要操作、喜悦、核心记忆 | `#ffe066` |
| 忧伤 | `#69b8ff` |
| 恐惧 | `#c49bff` |
| 愤怒 | `#ff717b` |
| 厌恶 | `#93d956` |
| 好奇（插件扩展维度） | `#67e2da` |
| 成功 / 中性记忆 / 中性封存球 | `#a6e282` / `#d5d3ed` / `#bab1ce` |

情绪色通过 CSS 变量同时用于记忆球、强度条和六色图例。主操作使用金色与深紫文字；已连接、已启用、开关及成功提示仍使用独立绿色。警告、错误和永久删除保留专用语义。没有明确情绪的普通记忆使用珠光中性色，不推断它属于某种情绪。

记忆球增加亮部、高光和柔和光晕；轨道仅为细线装饰。导航、统计卡、表单、模态、人格岛、档案和日志的旧墨绿表面一并改为蓝紫色，焦点环使用金色。
