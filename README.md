# dsh-pseudo-insideout

给 DeepSeek Harness 的记忆与状态插件：经历形成记忆，理解可以更新，退出日常召回的记忆完整封存。带可视化总部、记忆球、情绪控制台、人格岛、梦工坊及独立档案馆。

**系统不会因为时间、低权重、后台整理或容量限制自动删除已经保存的记忆。活跃库与封存库分开存放，日常召回不会打开封存数据库。**

项目采用瀑布流程完成需求、架构、详细设计、实现、测试及交付。当前版本 **0.0.1** 包含全局默认记忆开关、单会话三态覆盖，以及已有记忆、DSH历史会话和JSON/TXT/Markdown文件的显式导入。操作与边界见[会话开关和导入](docs/11-session-policy-import.md)。[交付验收报告](docs/08-delivery-report.md)区分自动测试、真实 DSH 配合本机合成模型的端到端验证、浏览器操作及未测边界。同时包含[成长能力](docs/10-growth-completion.md)与[Inside Out配色](docs/09-insideout-palette.md)。

版本号已统一重置为 `0.0.1`。设计文档中的 1.0–1.2 为开发阶段编号；历史验收记录仍对应原工件，不代表对新版本安装包重新执行了宿主或浏览器验收。

## 支持环境

- Node.js **24.9.0 或更高**。
- 本版已针对 **DSH 0.2.2-alpha.2 Web profile** 核对并实际安装、启动；其他 DSH 版本及 Desktop 原生壳不在已验证范围。
- 本机访问，SQLite 本地磁盘。暂不提供远程控制台或网络共享盘支持。
- 运行时不需要额外 npm 库或单独模型密钥。提炼与语义选择复用 DSH 的模型，可能分别增加一次完成后分析和一次下一回合前检索调用；失败时退回本地规则。

## 安装

将已打包的文件安装到自己的 Web profile，然后重启 DSH：

```sh
dsh plugin --profile web add /absolute/path/dsh-pseudo-insideout-0.0.1.tgz
dsh --profile web
```

在 DSH 设置打开 **记忆总部 · Pseudo Inside Out**；也可以在 DSH 本机地址下访问 `/pseudo-insideout/`。首次没有活跃会话时显示“未连接 DSH 会话”，不会伪造记忆或连通状态。

详细配置、升级、卸载和实际版本限制见 [安装维护手册](docs/06-installation.md)。本次开发只在隔离临时 profile 安装验收，没有修改用户既有 DSH 设置，也没有发布到 npm。

## 功能

| 模块 | 已实现行为 |
|---|---|
| 记忆开关 | 同一profile的全局默认；会话继承/单独开启/单独关闭；空间硬暂停优先；关闭不删除旧记忆 |
| 显式导入 | 选择已有记录/整个会话的当前快照、DSH完成回合或JSON/TXT/Markdown；先预览再选择提交，保留来源与原文，重复导入不复制 |
| 记忆球 | 正常对话自动提炼类型、重要度、主题、实体、日期及画像候选；原话单独保存，展示提炼依据、修订和新解释 |
| 活跃召回 | 宿主模型在有限活跃候选中做语义选择；中文/英文词、有限双语概念回退、日期/人物过滤和只读 DSH 检索工具；结果再次校验范围与预算 |
| 档案馆 | 独立数据库、分页查阅、显式封存、恢复、10分钟有效且单回合使用的临时调阅授权 |
| 情绪控制台 | 喜悦、忧伤、恐惧、愤怒、厌恶、好奇；严格结构化分析、置信度门槛、步长限制和自然回落 |
| 核心记忆 | 高重要度经历形成候选，批准后才成为核心；仍受可见范围和上下文预算约束 |
| 人格岛 | 偏好、关系、习惯、价值和兴趣候选，经审批后启用；成长时间线、版本回退和封存版本恢复；区分用户画像与 agent 人格 |
| 梦工坊 | 核心化、跨经历归纳、关联、旧事件封存、倾向和陈述核对；跟进遵守到期日、时区、安静时段及频率，全部为待审建议 |
| 会话工作台 | 目标、关注点、模拟精力与固定工作记忆；情绪给出表达建议并有限影响注意排序 |
| 回应依据 | 逐轮实际注入状态、入选/落选理由、辅助模型返回的 token 用量；不编造费用 |
| 回收箱与批量管理 | 移入回收箱可恢复且不自动清空；批量封存/恢复保持事务一致；永久删除另需完整 ID |
| 修复与追溯 | 乐观版本冲突、防重复事件、损坏记录告警、原文保留、派生链封存、无正文审计、显式删除 |
| 备份恢复 | 一致的双库快照、SHA-256 清单、完整性校验、恢复到新目录且清除旧调阅授权 |

“淡忘”仅改变召回优先级。整理默认关闭；启用也只提出建议，不自动清空、封存或改人格。约定跟进仅在控制台显示，不自动向外发消息。

语义选择使用 DSH 现有模型；离线回退是有限概念表和词法/结构匹配，不是 embedding 搜索，也不保证理解任意表达。会话记忆关闭会同时停止该会话的捕获、上下文、只读工具及辅助模型调用；若想继续使用本地记忆但禁用模型辅助，则同时设置宿主 `analyzeTurns:false` 和控制台 `semanticEnabled:false`。仅关闭情绪仍可提炼记忆。人格岛是可修正的倾向，不是心理诊断或意识。此项目借用电影的结构比喻，没有使用电影角色和素材。

在总部修改全局默认，在会话工作台选择“继承默认／单独开启／单独关闭”。单会话开启不能绕过空间硬暂停。回合中途改变开关后，该回合停止采集；重新开启从下一完整回合开始。关闭不会撤回DSH已经保存的旧上下文。

从记忆大厅或会话工作台打开导入，明确选择目标会话和来源。整会话只取预览时选定的记录，不跟随后续新增；已有记忆保持原ID与私有范围，仅向目标授权披露的记录及依赖。DSH历史只读取当前工作区/角色下完成的真人回合。文件最大512KiB，每批最多200条；JSON支持记录对象、数组、`memories`/`records`或`messages`数组。TXT/Markdown按连续文本分段。文件作为未经核验的外部参考保存；导入不会调用模型、改变情绪或开启目标会话记忆。

## 三种容易混淆的操作

1. **浏览档案**：仅显示在控制台，不向模型授权。
2. **临时调阅**：选定会话在一个符合条件的回合中新注入该条记忆；内容仍在封存库。
3. **恢复活跃**：重新加入此后日常召回候选。

DSH 会保存已经注入的上下文历史，因此临时调阅不能保证从以后可见的宿主历史中抹除。插件永久删除也不删除 DSH 对话、用户导出文件或系统备份。删除是单独的主动操作，需输入完整记忆 ID；绝不会由整理、情绪或衰减触发。

源经历被封存时，引用它的摘要与解释也会封存；关联人格岛停止使用。源内容修订后，旧派生内容进入档案等待重新建立。档案库还保存被撤回的关联建议、人格版本及模型提炼历史。模型见过的背景来源发生变化时，后续原话仍保留，受影响的提炼退回本地规则，旧提炼显式存入档案。恢复人格封存版本须恢复全部未修订来源并通过指纹校验；恢复后保持停用，需另行启用。

## 从源码使用

```sh
npm ci --ignore-scripts
npm test
npm start
```

`npm start` 启动本机 `http://127.0.0.1:3088/pseudo-insideout/`，数据存入项目的 `.insideout-dev/`，默认没有示例。它用于独立管理与界面验收，明确显示未连接 DSH。

要看到带记忆球的合成演示，使用单独目录：

```sh
node scripts/serve.js --data-dir .insideout-demo --port 3089 --demo
```

示例全部标记“演示数据”，不连接模型。请勿把示例目录用作真实会话数据根。

打包：

```sh
npm pack --dry-run
npm pack
```

## 数据与备份

每个 profile / workspace / agent 使用独立的数据根，里面只有本范围的记忆数据：

```text
active/insideout.sqlite     活跃原文、索引、状态、无正文目录与操作记录
archive/insideout.sqlite    封存原文、版本、独立索引及关联快照
```

数据库使用 SQLite 回滚日志及跨文件事务。普通召回只访问 active。全文索引和数据库都启用安全删除选项，避免已封存内容留在当前活跃索引页；这不等同于对 SSD、系统快照的取证级擦除。

DSH profile根另有 `memory-default.sqlite`，只保存默认开关及版本，不保存会话正文；会话覆盖、显式导入授权在各自活跃库。独立控制台默认设置也在本目录活跃库。下列脚本备份一个记忆空间，不包含DSH profile根的默认开关；整体迁移应停用宿主后另行保留profile数据根及`scopes.json`。

明确备份一个数据根：

```sh
node scripts/backup.js create --from /absolute/data-root --to /absolute/new-backup
node scripts/backup.js restore --from /absolute/new-backup --to /absolute/new-data-root
```

目标目录必须不存在。备份脚本在同一事务锁下复制两库；恢复校验哈希与 SQLite 完整性，并清空临时调阅授权。将恢复目录接回 DSH 前先停止对应插件，保留原数据目录供核对。不要在宿主运行时用单文件复制代替完整备份。

自动捕获只处理正常完成的根会话真人消息。取消、失败回合与子 agent 不进入捕获；配额已满、捕获关闭及过大输入等核心捕获跳过会记录原因。插件不承诺把宿主的所有字节和工具输出都复制成记忆。已存记忆不会因此受影响。
