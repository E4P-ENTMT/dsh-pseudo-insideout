# dsh-pseudo-insideout

给 DeepSeek Harness（DSH）的记忆插件。让对话中的偏好与经历成为后续交流的参考，并在控制台查看、修订、导入或封存这些记忆。

[安装](#安装) · [第一次使用](#第一次使用) · [日常操作](#日常操作) · [常见问题](#常见问题) · [完整使用指南](docs/usage.md)

## 安装

使用前准备好 **Node.js ≥24.9.0** 和 DSH **Web profile**。支持的 DSH 版本为 **`0.2.1-rc.1` 至 `0.2.1-rc.5`、`0.2.2-alpha.2`**。控制台仅支持本机访问，Desktop 原生壳尚未验证。

当前插件版本为 `0.0.1`，尚未发布到 npm。在下载或克隆的仓库目录中生成安装包：

```sh
npm ci --ignore-scripts
npm pack
```

将生成的包安装到 DSH。下面以名为 `web` 的 Web profile 为例；如果你的 profile 名不同，请替换 `web`：

```sh
dsh plugin --profile web add "$(pwd)/dsh-pseudo-insideout-0.0.1.tgz"
```

如果已有 `.tgz` 安装包，可跳过打包步骤，将命令中的路径换成该文件的绝对路径。

安装后重启对应的 DSH profile；尚未运行时可直接启动：

```sh
dsh --profile web
```

在 DSH 设置中打开 **记忆总部 · Pseudo Inside Out**。也可以在 DSH 当前的本机地址后加上 `/pseudo-insideout/` 打开控制台。升级或卸载方法见[安装维护手册](docs/06-installation.md#停用卸载与升级)。

## 第一次使用

1. **打开一个 DSH 主会话。** 自动记录面向正常对话，不包含子 agent 会话。
2. **确认记忆已开启。** 在控制台选择对应记忆空间，进入「总部」的「会话工作台」，选定会话并点击「切换会话」，确认显示「当前生效：开启」。如果空间已暂停，先点击「恢复此记忆空间」。
3. **完成一轮对话。** 例如告诉 DSH：「我喜欢简洁的回答，解释代码时先给结论。」等待回复正常结束。
4. **查看保存结果。** 回到控制台点击右上角「刷新数据」，打开「记忆大厅」，点击新记忆，核对原始经历、来源会话与提炼依据；需要更正时可以修订。
5. **试一次召回。** 在同一会话继续问：「你还记得我喜欢怎样的回答吗？」完成后刷新控制台，到「运行与设置」的「按轮回应依据」中选定会话，查看这条记忆是否进入本轮上下文。

之后正常聊天即可。记忆默认按会话隔离，切换到另一个会话后，如需沿用旧记忆，请通过下方的导入操作明确选择。

辅助提炼和语义检索复用 DSH 的模型与凭据，可能产生额外模型费用，无需另填 API 密钥。模型不可用时会回退本地规则；只使用本地记忆的方法见[关闭辅助模型调用](docs/06-installation.md#辅助模型调用与关闭方式)。

## 日常操作

### 开启或关闭记忆

在「总部」的「会话工作台」中选定会话，选择设置后点击 **保存会话记忆设置**：

| 设置 | 适合什么时候用 |
|---|---|
| 继承默认 | 跟随当前 DSH profile 的默认开关 |
| 本会话开启 | 只为这个会话开启，即使全局默认关闭 |
| 本会话关闭 | 停止这个会话的自动捕获、召回和记忆辅助模型调用 |

要调整同一 profile 的默认值，在「总部」的「默认记忆开关」中修改 **默认启用会话记忆**，再点击 **保存默认开关**。独立设置的会话不受影响。

要暂停整个记忆空间，点击「总部」顶部的 **暂停此记忆空间**；空间暂停优先于会话开启。关闭或暂停都保留已有记录，仍可手动管理和导入。回合中途关闭后再开启，要等下一完整回合才恢复采集。

### 导入旧会话或文件

1. 在「记忆大厅」点击 **导入记忆**，或在「总部」的「会话工作台」点击 **导入到此会话**。
2. 确认目标会话，选择已有活跃记忆、DSH 历史会话或 JSON / TXT / Markdown 文件。
3. 点击 **生成导入预览**，核对来源和内容，勾选需要的记录。
4. 确认导入所选记录。要让它们参与后续对话，还需确认目标会话记忆已开启。

文件最大 **512 KiB**，每批最多 **200 条**，预览有效期 **10 分钟**。导入不会自动开启记忆，不调用模型，也不会重复复制已导入内容。各来源的处理方式见[导入说明](docs/usage.md#导入已有资料)。

### 保存一条重要记忆，或暂时不再使用它

| 想做什么 | 在哪里操作 |
|---|---|
| 手动记录 | 「记忆大厅」→「新建记忆」 |
| 让某条记忆优先参与召回 | 打开活跃记忆详情 →「加入工作记忆」，指定目标会话 |
| 保留内容，但退出日常召回 | 打开记忆详情 →「封存记忆」，填写原因并确认 |
| 让封存内容重新参与日常召回 | 「封存档案馆」→ 打开记忆 →「恢复活跃」 |
| 仅在一个回合中使用封存内容 | 「封存档案馆」→ 打开记忆 →「临时调阅」，选择会话并授权 |

**已保存的记忆不会因时间、低权重或容量限制自动删除。** 浏览档案不会把内容发给模型；临时调阅与恢复活跃需要单独操作。插件无法撤回已经写入 DSH 会话历史的内容。回收箱与永久删除规则见[档案操作说明](docs/usage.md#封存临时调阅与恢复)。

### 整理记忆与查看成长建议

积累一些对话后，在「梦工坊」点击 **整理一次**，查看归纳、关联、核心记忆或人格岛建议，核对依据后再批准或拒绝。需要自动生成建议时，在「运行与设置」开启 **后台整理建议** 并保存配置；此功能默认关闭。

「人格岛」可查看已有倾向及其支持记忆。「总部」展示模拟情绪状态。这些内容用于辅助交流，不是心理诊断；跟进建议只显示在控制台，不自动向外发送消息。

## 常见问题

| 遇到的情况 | 先检查什么 |
|---|---|
| 显示「未连接 DSH 会话」 | 确认打开的是 DSH 内入口，并已打开主会话；下方的独立预览始终不连接 DSH |
| 对话后没有新记忆 | 先点击「刷新数据」，再确认会话已开启、空间未暂停，「运行与设置」中已开启「捕获新记忆」；取消或失败的回合不会保存为完整经历，跳过原因可查「操作日志」 |
| 有记忆，但回答没有用上 | 确认会话和记忆空间选对、记忆仍处于活跃状态；查看「按轮回应依据」中的入选记录与未入选原因 |
| 导入预览失效或来源有变化 | 重新生成预览，再勾选提交 |
| 想保留本地记忆，但不产生额外模型调用 | 同时关闭宿主的 `analyzeTurns` 和各空间的「允许受控语义检索」，见[配置步骤](docs/06-installation.md#辅助模型调用与关闭方式) |

数据保存在本机。升级、迁移或备份前，先阅读[数据位置](docs/06-installation.md#数据位置与隔离)和[备份与恢复](docs/06-installation.md#备份与恢复)；整个 profile 的备份需要包含默认开关、空间目录及活跃与封存数据。

## 独立预览控制台

想先看看界面，可在仓库目录安装依赖后运行：

```sh
npm ci --ignore-scripts
npm start
```

打开 [本机预览](http://127.0.0.1:3088/pseudo-insideout/)。默认没有示例，数据保存在 `.insideout-dev/`。独立预览可手动管理记忆，不连接 DSH 对话。

如需带示例的演示，使用单独的数据目录：

```sh
node scripts/serve.js --data-dir .insideout-demo --port 3089 --demo
```

打开 [演示控制台](http://127.0.0.1:3089/pseudo-insideout/)。示例标记为「演示数据」，不调用模型；请勿将演示目录用作真实会话数据目录。
